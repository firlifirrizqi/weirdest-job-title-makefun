# Weirdest Job Title

Entry for [Weirdest Job Title: Blind Judge Showdown](https://make.fun/competitions/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) on make.fun.

A single job title, 60 characters or fewer and nothing else. A blind judge
compares titles two at a time and picks the weirder, funnier one — so this
entry starts from a believable job shape (Chief Negotiator) and adds one
hilariously specific twist: the machines being negotiated with are haunted
vending machines.

## The title

> Chief Negotiator for Haunted Vending Machines

45 characters.

## How it works

`main.py` (standard library only) writes exactly that title to
`/output/entry.txt`, after checking it against the kit's gate: 1–60
characters, a single line, no leading or trailing whitespace, and the
expected word count. It then reads the file back and confirms it is
byte-identical to the title.
